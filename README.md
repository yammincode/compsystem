# 攀岩比賽報名系統

參賽者可在網站上選擇組別報名，公開名單會顯示 **匿名姓名、組別、所屬團體**。
未來第二個頁面（`/results`）會依組別轉為比賽成績系統，目前先放置「建置中」頁面。

## 功能

| 頁面 | 路徑 | 說明 |
| --- | --- | --- |
| 報名頁 | `/` | 填寫姓名、選擇組別、填寫所屬團體（選填）；下方為公開報名名單，可依組別篩選、搜尋 |
| 比賽成績 | `/results` | 預留給之後的成績系統 |
| 管理頁 | `/admin` | 需密碼登入。新增／編輯／刪除組別、設定人數上限、開關報名；查看真實姓名、編輯／刪除報名、匯出 CSV |

### 姓名匿名規則

| 原始姓名 | 公開顯示 |
| --- | --- |
| 王小明（三個字） | 王X明 |
| 王明（兩個字） | 王X |
| 歐陽小明（四個字以上） | 歐XX明（保留頭尾） |

匿名化在 **伺服器端** 完成（`lib/anonymize.js`），公開 API 完全不會傳出真實姓名，只有登入的管理員看得到。

### 其他規則
- 同一組別中「姓名 + 所屬團體」相同視為重複報名，會被拒絕。
- 組別可設人數上限，額滿或關閉報名的組別無法選擇。
- 已有人報名的組別不能刪除（請改為關閉報名）。

## 執行

需要 **Node.js 22.13 以上**（使用內建的 `node:sqlite`，不需要安裝任何套件）。

```bash
ADMIN_PASSWORD=你的密碼 npm start
# 開啟 http://localhost:3000
```

環境變數：

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `ADMIN_PASSWORD` | 隨機產生並印在終端機 | 管理頁密碼 |
| `PORT` | `3000` | 監聽埠號 |
| `DB_FILE` | `data/compsystem.db` | SQLite 資料庫檔案位置 |

第一次啟動會自動建立三個範例組別（男子公開組、女子公開組、青少年組），可在管理頁修改或刪除。

## 測試

```bash
npm test
```

## 專案結構

```
server.js          HTTP 伺服器與 API
lib/db.js          SQLite 資料表（categories、registrations）
lib/anonymize.js   姓名匿名規則
public/            前端頁面（報名、成績、管理）
test/              自動化測試
```

## 之後的成績系統

`registrations` 已有 `category_id` 與每位選手的 `id`，之後可新增 `results` 資料表
（例如 `registration_id`、`route`、`tops`、`zones`、`attempts`），在 `/results` 依組別顯示排名。
